# Example Chart Review Output

This is a format example, not a trader-specific claim.

## Mentor Review

### First Read

Price is reacting around a key area, but the chart needs higher-timeframe context before the idea is complete.

### What Is Clear

- Current price is near a visible reaction zone.
- There is likely liquidity resting above the recent high and below the recent low.
- The user has a directional idea but has not fully defined invalidation.

### What Is Missing

- 1h/4h structure
- Clear invalidation
- Whether this is a continuation setup or a range trade
- Confirmation trigger

### Higher-Timeframe Context

Check whether the current area is support, resistance, or the middle of a larger range. Avoid treating a lower-timeframe bounce as meaningful if the higher timeframe is still pushing into resistance.

### Key Levels And Liquidity

Mark the nearest clean highs and lows. If price is between both, be careful about entering in the middle.

### Bullish Case

The bullish case improves if price reclaims the level, holds above it, and forms a clean lower-timeframe trigger with invalidation below the reclaim.

### Bearish Case

The bearish case strengthens if price rejects the level and starts accepting below it, especially if the move traps late longs.

### Invalidation

The idea is incomplete without a level that proves the setup wrong.

### Risk And Execution Notes

Do not size a trade around hope. Define the invalidation first, then decide if the target gives enough reward.

### Suggested Chart Additions Or Cleanup

- Add 1h and 4h levels.
- Mark liquidity above and below.
- Mark the exact invalidation.
- Remove indicators that are not part of the decision.

### Does This Match The Trader Profile?

Not enough trader-specific evidence yet. This follows the base mentor framework until more public sources are added.

### Questions Before Trading

- Where is the higher-timeframe invalidation?
- Are you entering at a level or in the middle?
- What confirms your idea before entry?
- What cancels it immediately?
