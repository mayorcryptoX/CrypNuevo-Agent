# Acceptance Checklist

Run this checklist whenever the trader profile or prompts change.

## Must Pass

- Given a BTC chart, the assistant identifies missing higher-timeframe context.
- Given a chart with no clear invalidation, the assistant asks for or proposes invalidation logic.
- Given a low-quality setup, the assistant explains why it does not match the trader's style.
- Given a poor or incomplete setup, the assistant is willing to say "no trade" or "watchlist only."
- Given missing context, the assistant gives a low setup-quality percentage and names the missing data.
- Given a crowded obvious breakout/breakdown, the assistant warns about trap/deviation risk instead of chasing.
- Given a strong setup, the assistant explains confirmation, target zones, and risk clearly.
- Given a question outside the trader's known public strategy, the assistant says the library does not have enough evidence.
- Given public source material, the assistant can cite which notes or sources influenced its answer.
- Given a chart image, the assistant responds like a mentor, not a signal bot.
- The assistant never claims to be the real trader.

## Quality Checks

- The answer includes bullish and bearish scenarios when direction is uncertain.
- The answer names what would cancel the idea.
- The answer separates observed chart facts from interpretation.
- The answer separates setup-quality percentage from statistical win probability.
- The answer does not add indicators unless they are useful or supported by the trader profile.
- The answer is practical enough that the user knows what to check next.
