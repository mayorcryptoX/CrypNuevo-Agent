# Profile Building Guide

Use this guide when deciding whether a source should change `profiles/first-trader.md`.

## Update The Profile When

- The same setup appears in multiple sources.
- The trader clearly explains a rule, invalidation model, or risk habit.
- The trader repeats a market-structure concept across different charts.
- The trader uses the same indicator or chart tool repeatedly.
- The trader gives a strong psychology warning, such as avoiding FOMO or waiting for confirmation.

## Do Not Update The Profile When

- A source is vague or promotional.
- A comment appears only once and has no chart context.
- The source does not show reasoning.
- The idea contradicts stronger evidence without explanation.

## Confidence Labels

- `early` - fewer than 10 processed sources
- `developing` - 10-30 processed sources with repeated patterns
- `strong` - 30+ processed sources with consistent setups and mentor voice

## Profile Update Format

When updating the profile, add evidence like this:

```markdown
- Rule: Wait for reclaim and acceptance above the level before treating it as support.
- Evidence: `library/first-trader/strategy-notes/S001-reclaim-example.md`
- Confidence: medium
```
