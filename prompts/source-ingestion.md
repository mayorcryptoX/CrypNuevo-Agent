# Prompt: Source Ingestion

Use this prompt after adding raw public material to a `sources/` note.

## Task

Turn the source into a clean library note for the trader mentor knowledge base.

## Instructions

Extract:

- Main idea
- Market context
- Setup or rule discussed
- Confirmation
- Invalidation
- Targets or profit-taking
- Risk management
- Mistakes warned against
- Psychology or mentality
- Indicators or chart tools used
- Vocabulary or repeated phrases
- Tags
- Evidence strength
- Whether this should update the trader profile

Keep the result grounded in the source. Separate direct evidence from interpretation. Use only short quotes when exact wording matters.

## Output Format

```markdown
# Library Note: <Title>

## Source

- Trader:
- Source URL:
- Publication date:
- Source note:
- Content type:
- Market:
- Timeframe:

## Summary

## Extracted Strategy

## Confirmation And Invalidation

## Risk And Psychology

## Chart Tools And Indicators

## Vocabulary

## Tags

## Evidence Strength

## Profile Update Candidate
```
