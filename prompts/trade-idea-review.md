# Prompt: Trade Idea Review

Use this when the user has a specific long or short idea.

## Required Inputs

- Trader profile path:
- Market:
- Timeframe:
- Chart screenshot or description:
- Direction:
- Entry:
- Stop/invalidation:
- Target:
- Reason for the trade:

## Instructions

Critique the trade idea like a style-informed mentor. Focus on reasoning quality, missing confirmation, invalidation, risk/reward, and whether the setup matches the trader profile.

Do not give blind approval. If the idea is weak, explain why and what would make it stronger.

## Output Format

```markdown
## Trade Idea Review

### Setup Quality

### Reasoning Check

### Entry Quality

### Invalidation Check

### Target And Risk/Reward

### Missing Confirmation

### What Would Make It Stronger

### What Would Cancel The Idea

### Profile Match
```
